# Claude Log Viewer

A Rust-based terminal UI (TUI) tool for viewing and analyzing Claude Code transcript JSONL files using [ratatui](https://github.com/ratatui-org/ratatui).

## Features

- **Parse Claude Code JSONL transcripts**: Comprehensive support for all Claude Code transcript entry types
- **Interactive TUI**: Navigate through conversation history with keyboard controls
- **Rich Detail View**: See full message content, tool usage, token statistics, and more
- **Multiple Input Formats**: Load from single files, directories, or Claude projects
- **Token Usage Tracking**: Display detailed token consumption statistics
- **Smart Sorting**: Automatically sorts entries chronologically

## Supported Entry Types

- **User Messages**: User prompts and tool result submissions
- **Assistant Messages**: Claude's responses with token usage tracking
- **Summary Entries**: Session summaries generated by Claude
- **System Messages**: System warnings and notifications
- **Queue Operations**: Internal message queue tracking (enqueue/dequeue)

## Content Types

The viewer supports all Claude Code content types:

- **Text**: Regular text content
- **Tool Use**: Tool invocations (Bash, Edit, Read, Write, etc.)
- **Tool Results**: Results from tool executions
- **Thinking**: Claude's internal reasoning (extended thinking mode)
- **Images**: Base64-encoded images with metadata

## Installation

### Prerequisites

- Rust 1.70+ (Install from [rustup.rs](https://rustup.rs))

### Build from Source

```bash
# Clone this repository
git clone <your-repo-url>
cd claude-log-viewer

# Build the project
cargo build --release

# Run the binary
./target/release/claude-log-viewer <path>
```

### Install Locally

```bash
cargo install --path .
```

## Usage

### Basic Usage

```bash
# View a single JSONL file
claude-log-viewer path/to/transcript.jsonl

# View all transcripts in a directory
claude-log-viewer path/to/transcript/directory

# View a Claude Code project (looks in ~/.claude/projects/)
claude-log-viewer my-project-name
```

### Full Path Examples

```bash
# Using full path to Claude project
claude-log-viewer ~/.claude/projects/-Users-navicore-git-myproject

# Using test data from the Python project
claude-log-viewer ~/tmp/git/claude-code-log/test/test_data/representative_messages.jsonl
```

### Keyboard Controls

- **↑** or **k**: Move up in the entry list
- **↓** or **j**: Move down in the entry list
- **q** or **Esc**: Quit the application

## Understanding Claude Code JSONL Format

Claude Code stores conversation transcripts as newline-delimited JSON (JSONL) files. Each line is a complete JSON object representing one transcript entry.

### Key Fields

All entries (except summaries) have these common fields:

- `type`: Entry type ("user", "assistant", "summary", "system", "queue-operation")
- `timestamp`: ISO 8601 timestamp
- `sessionId`: Unique session identifier
- `uuid`: Unique entry identifier
- `cwd`: Current working directory
- `userType`: User type (usually "human")
- `version`: Transcript format version

### Example Entry

```json
{
  "type": "user",
  "timestamp": "2025-07-03T15:50:07.874907Z",
  "sessionId": "test_session",
  "uuid": "msg_001",
  "cwd": "/tmp",
  "userType": "human",
  "version": "1.0.0",
  "parentUuid": null,
  "isSidechain": false,
  "message": {
    "role": "user",
    "content": [
      {
        "type": "text",
        "text": "Hello Claude!"
      }
    ]
  }
}
```
